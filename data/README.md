# データの書き方

教材の中身は `data/items/<項目番号>.json` に、1項目1ファイルで書きます（例：`8-1.json`）。
アプリのプログラム（`app.js`）には触らずに、ここを書き換えるだけで画面が変わります。

## 中国語の書き方

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `{漢字\|ピンイン}` | 漢字の下にピンイン | `{了\|le}` |
| `{漢字\|ピンイン\|実際の発音}` | 声調が変わる字（点線。押すと実際の発音） | `{我\|Wǒ\|Wó}` |
| `[文字]` | 問題の空欄や記号 | `[（　）]`、`[A]` |
| `**文字**` | 太字 | `着い**た**ら` |

- ピンインは単語ごとにつなげて書く（`{买了|mǎile}`）。文頭は大文字（`Wǒ`）
- 中国語の文では、単語の間に半角スペースを入れてよい（画面では消え、コピーしても漢字だけがつながる）
- `{ } | [ ]` は必ず**半角**。全角の `｛ ｝ ｜` は誤り

## JSON の決まり（ここで間違えやすい）

- 文字は必ず `"` （半角のダブルクォート）で囲む
- 項目の区切りは `,`。**最後の項目の後ろには `,` を付けない**
- `"checked": false` は「ネイティブ未確認」。確認できたら `true` にする

## 1項目のファイルの形

```
{
  "id": "8-1",                       ← ファイル名と同じ
  "chapter": { "no": 8, "ja": "アスペクト", "en": "Aspect" },
  "title": { "ja": "完了の{了|le}", "en": "Perfective {了|le}" },
  "terms": "用語の説明",
  "lecture": [ 講義のブロック… ],
  "examples": [ 例文… ],
  "quiz": [ 振り返り問題… ]
}
```

### 講義のブロック（`type` で種類を決める）

| type | 中身 | 必要な項目 |
| --- | --- | --- |
| `map` | この章の地図 | `title`, `cells`（`zh`, `ja`, `current`） |
| `text` | 見出し＋文章 | `title`, `body` |
| `pattern` | 型 | `title`, `ja`, `en`, `zh` |
| `panel` | 灰色の枠の文章 | `title`, `body` |
| `compare` | ほかの言語との比較 | `title`, `cards`（`label`, `body`） |
| `debate` | 説が分かれる点 | `title`, `body` |

ブロックに `"id": "pattern"` のような名前を付けると、問題の解説の「講義の該当箇所 ›」から、そこへ飛べます。

### 例文

- ふつうの例文：`zh`, `ja`, `en`（`note` は任意）
- 誤用例：`"kind": "wrong"`（誤った文）か `"kind": "odd"`（不自然な文）と、`zh`, `explain`

### 振り返り問題

- 並べ替え：`"type": "reorder"`、`tokens`（カード）、`answer`（正しい順番。0 が1枚目）
- 選択式：`"type": "choice"`、`options`（選択肢）、`answerIndex`（正解。0 が1つ目）
- 共通：`kind`, `promptJa`, `promptEn`, `correct`, `ja`, `en`, `why`, `lecture`

## 書いたら確かめる

```
node tools/check-data.js
```

誤りがあれば、どのファイルのどこが、なぜ誤りかを表示します。
