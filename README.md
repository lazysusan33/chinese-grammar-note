# 中国語文法ノート（試作）

HSK3〜4級程度の語彙をもつ日本語話者が、中国語の文法を言語学の体系に沿って「講義 → 例文 → 問題」の順に学ぶための、スマホ向けの学習ツールです。

- 作り方：素の HTML・CSS・JavaScript（フレームワークなし）
- ファイル：`index.html`（骨組み）、`style.css`（見た目）、`app.js`（動き）、`data/items/*.json`（教材の中身。書き方は `data/README.md`）
- データの確認：`node tools/check-data.js`
- 教材：講義・例文・問題はすべてオリジナル。例文はネイティブ確認前のものを含みます
